1. Name of my project:
Keen Keeper

2. A short description:
Keen Keeper is a web app that helps me manage and track my friendships, monitor interactions, and maintain meaningful connections easily.

3. Technologies I used:
React.js, React Router, Tailwind CSS, Recharts, Context API, React Hot Toast

4. 3 key features of my project:

Friend management with status tracking (On-Track, Overdue, Almost Due)
Interaction analytics with Pie Chart visualization
Timeline system to track and manage friend interactions
